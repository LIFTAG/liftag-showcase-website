# Pivot Leg Press recording assets

These assets are generated by `new_app/tools/recording/build_pivot_leg_press.py`.

- `pivot-leg-press-mannequin.glb`: Y-up, metre-scale mannequin with the 4.8-second `PivotLegPressCycle` animation.
- `pivot-leg-press-motion.json`: shared timing, world transform, and existing-machine carriage displacement.
- `pivot-leg-press-demo.mp4` / `.webm`: silent 30 fps logger preview rendered from the authored scene.
- `pivot-leg-press-poster.webp`: matching 720×405 poster frame.

The GLB excludes the leg-press machine so the live stage can reuse its existing exact machine geometry. Drive `LiftagPressCarriage` from the normalized samples in the JSON while setting the mannequin animation mixer to the same visible playback time.
